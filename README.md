# Sales_Management_Analysis
Sales management analysis project using SQL Server , Python and Power BI.

## Project Overview
This project is based on sales management data. The data was initially prepared in Excel and then imported into SQL server.

In SQL Server , I designed the database structure, created tables and relationships, added constraints, and worked with stored procedures, audit triggers,
and SQL reports.

I then connected the SQL Server data with Python for data checking and analysis. Finally, I used Power BI to build a dashboard covering sales, profit and loss,
customer,product,salespersons,regions, and payment details.

## Tools Used

- Excel
- SQL Server
- Python
- Pandas
- Matplotlib
- Power BI
